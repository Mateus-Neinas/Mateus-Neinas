## Projetos em destaque

### CoreERP — ERP modular de demonstração

Projeto dividido em repositórios para demonstrar integração entre tecnologias e responsabilidades:

| Módulo | Tecnologias | Repositório |
|---|---|---|
| API REST | Node.js, JavaScript | [coreerp-api](https://github.com/Mateus-Neinas/coreerp-api) |
| Backend de relatórios | Java 21, Maven | [coreerp-backend-java](https://github.com/Mateus-Neinas/coreerp-backend-java) |
| Interface web | React, Vite | [coreerp-web-react](https://github.com/Mateus-Neinas/coreerp-web-react) |
| Banco e migrações | PostgreSQL, SQL | [coreerp-database](https://github.com/Mateus-Neinas/coreerp-database) |
| Estoque e compras | JavaScript | [coreerp-inventory](https://github.com/Mateus-Neinas/coreerp-inventory) · [coreerp-purchasing](https://github.com/Mateus-Neinas/coreerp-purchasing) |
| Financeiro | JavaScript | [coreerp-finance](https://github.com/Mateus-Neinas/coreerp-finance) |
| Testes | Node.js, Cypress | [coreerp-api-tests](https://github.com/Mateus-Neinas/coreerp-api-tests) · [coreerp-cypress-e2e](https://github.com/Mateus-Neinas/coreerp-cypress-e2e) |

> **Estado do projeto:** demonstração em evolução. O esquema PostgreSQL está versionado, mas a API ainda usa dados em memória e não persiste no banco.

## Tecnologias e práticas

**Desenvolvimento:** Java, JavaScript, React, Node.js, SQL  
**Qualidade:** testes de API, Cypress E2E, validação de entradas  
**Entrega:** Git, GitHub, pull requests, revisão de código e CI com GitHub Actions

Estou aprofundando essas tecnologias por meio dos projetos publicados; cada repositório documenta seu objetivo, execução e limitações.

## Como organizo os projetos

Uso um fluxo Kanban: **Backlog → Pronto → Em andamento → Revisão → CI → Merge → Concluído**. Tarefas podem ser divididas entre coordenação e papéis especializados de implementação, QA, DevOps e documentação; as mudanças são integradas por pull request.
